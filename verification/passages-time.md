# Passages time verification

Each row is a separate assertion. A scenario can satisfy several rows in one execution, but each result is recorded independently. These instructions are a maintainer runbook, not a claim that they ran. “blocked — unrun” means no runtime result was collected, not that source reading failed. Shared interruption scenarios must use disposable state.
