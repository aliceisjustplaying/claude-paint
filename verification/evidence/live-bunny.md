# Space Bunny provider run

The real `opencode-go` / `space-bunny-free` run at `xhigh` completed with 24 successful paint calls across manual compaction and fresh-session recovery. Seven Lua errors were followed by successful painting; one oversized crop was rejected. Replaying the successful log produced a byte-identical image and checkpoint. [Run results](live-bunny/summary.json), [session records](live-bunny/sessions-report.json), [log comparison](live-bunny/log-verification.json), [replay hashes](live-bunny/replay-comparison.json).

The run used source `4e525e50897807e9b5f734071dfeb330f1a393d3`, with round 23 in its ancestry. The legacy-named exporter was explicitly overridden to that revision. It ran from 13:02:54 to 13:41:48 UTC on October 4, 2026. [Build provenance](live-bunny/provenance.json), [timed results](live-bunny/summary.json).

The Lua failures involved an unsupported pencil option, missing parentheses, a boolean where a number was required, a global absent after a failed chunk and a pressure table where a scalar was required. These are model input errors, not seven product defects. The exact failures and subsequent successful calls are retained in [recovery pairs](live-bunny/lua-recoveries.json). The final [journal](live-bunny/journal.md) and [image](live-bunny/final.png) are preserved.

The run exposed a viewer defect: the painting clock could remain absent throughout ordinary successful painting. Successful paint replies did not automatically include the clock; the viewer depended on printed timestamps and ignored the clock in compaction/recovery summaries. The same conditional display existed in the downloaded production viewer. [Diagnosis](live-bunny/clock-diagnosis.json), [production HTML](live-bunny/production-viewer.html), [before screenshot](live-bunny/clock-before.png), [B23](../../bug-triage.md#b23--painting-clock-can-stay-absent-during-painting).

An isolated fix adds the current clock to successful paint replies, reads recorded clocks from recovery/compaction summaries and displays “not recorded” when no timestamp exists. It is saved as a [patch](live-bunny/painting-clock.patch) and [Git bundle](live-bunny/painting-clock.bundle), based on `4e525e5`, with local commit `2a705f4` on `fix/painting-clock`. That commit predates the instruction to stop committing. It is not integrated or deployed. [Preservation record](live-bunny/preservation.json).

Fix verification passed 51 harness tests, 25 studio tests and 10 session-integrity tests. The new regressions failed before the fix. A separate real Space Bunny probe created a canvas and waited 60 painting minutes without printing timestamps; replies contained `day 1, 09:00` and `day 1, 10:00`, and the viewer displayed one hour. The first probe brief omitted required canvas fields; that verifier setup error is recorded separately. [Harness](live-bunny/clock-harness-after.txt), [studio](live-bunny/clock-viewer-after.txt), [integrity](live-bunny/clock-rust-after.txt), [before native test](live-bunny/clock-regression-before.txt), [before viewer tests](live-bunny/clock-viewer-before.txt), [provider probe](live-bunny/clock-provider.jsonl), [probe screenshot](live-bunny/clock-provider.png), [setup correction](live-bunny/clock-probe-setup.txt).
