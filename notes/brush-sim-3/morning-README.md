# Morning engine study
This 18-stroke developer demo shows a pale vessel and a lit window against a freshly painted dark wall; compare spent dark contact, thick pale paint and the two clean-brush blends around the window.
Render at 1200 px with the same seed and stroke sequence for engine 5 and the experimental engine selected by root, once each after that preset is pushed; export Color and Gallery 115/55/1 from each final canvas using `--gallery --also-color`.
The comparison script places baseline and experiment directly side by side in separate native Gallery and Color sheets, adds a combined two-view sheet and makes two 1:1 details from those PNGs, without image filters; each output must stay under 20 MB.
This is an engine demo for Alice, with a fixed subject and gestures; it is not a painter brief or a finished painting, and Gallery brightness alone does not prove a paint-thickness improvement.
