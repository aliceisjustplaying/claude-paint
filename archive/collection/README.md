## What is tracked in Git

- Each painting and studio page links its records, including files already tracked elsewhere in the repository.
- [Source map](sources.json): original location, original SHA-256, destination, stored SHA-256 and whether identity redaction changed the copy. Home paths use `~`; the account name uses the public pseudonym.
- [Catalog](catalog.json): gallery and studio relationships, runner final images and replay-source links.
- Alternate gallery video versions are under `gallery/versions/`. Other runner and recent-round records are under `runners/` and `supplements/`; the source map includes their exact destinations.
- [Source commit references](source-refs.json): local preservation tags pin both receipt-named commits and the current worktree commits. Existing receipts and round tags were not rewritten. These tags have not been pushed.

## What stays private and outside Git

The ignored directory `.preservation/20261006T133149Z/` at the repository root holds:

- `records.tar.gz`: 32,528 verified files, including 852 raw session files, exact studio originals, runner data, gallery data and Git object databases.
- `gallery-history.tar.gz`: 508 verified historical gallery assets.
- `additional-originals.tar.gz`: 68 exact originals imported after the first archive inventory.
- `INDEX.md` and `catalog.json`: private gallery/studio index and original metadata.
- `files.json`, `gallery-history-files.json` and `additional-originals.json`: archive-member checksums.
- `verification.json`: verification results for the main archive.

Archive member names retain their original home-relative paths. Restoring into a separate empty directory preserves that layout without overwriting the active studios. Build caches and generated website `dist` directories are excluded; pinned easel binaries are retained.

This is a local, point-in-time preservation copy, not an off-machine backup or a recurring backup. No archives were uploaded to the VPS. Private archives are not included in a Git clone.

## Fidelity and known limits

Public-facing copies redact the local account name and home directory. They are not byte-identical when `identity_redacted` is true; exact originals are retained privately. The existing gallery prompt-extraction coverage report retains its historical missing-input notes; archiving it does not recover information that was never recorded.

All 75 gallery entries resolved to preserved session files and finished images in this round. The 60 studio pages include nongallery work without inventing gallery titles or completion status. Old source commits referenced by the inspected render receipts still exist and are pinned by local preservation tags; the reported checkout/receipt mismatch is not repaired by this collection.
