# Delivery verification

Each row is a separate assertion. A scenario can satisfy several rows in one execution, but each result is recorded independently. These instructions are a maintainer runbook, not a claim that they ran. “blocked — unrun” means no runtime result was collected, not that source reading failed. Shared interruption scenarios must use disposable state.

## Replay

Fixtures are independent and disposable. **E** means the default release easel with replay/finish features, an isolated EASEL_ROOT and the successful [probe source](evidence/probe.lua) when a painted canvas is needed. An empty-session row explicitly omits that canvas setup. **F** adds scripts/finish_painting and a closed studio layout with paintings/lua/painting.lua and out/easel/painting outputs. **V** adds scripts/replay_clip, ffmpeg/ffprobe and an owned frames.tsv directory. **X** adds scripts/export_r16_studio, Git refs and build dependencies; export always uses a new temporary destination and dedicated STUDIO_BUILDS. Exported-binary rows execute the delivered bin/easel from that studio. Python-related operations use uv and a virtual environment. Controls, comparisons and failures are separate cases within their row, not one combined scenario. Temporary failure targets never contain original source or user paintings.
