# Engine 9 license and data inventory

Audited 2026-10-22. The root Cargo resolution now has **85 packages**, including
the two MIT workspace packages, and no noncommercial dependency. Mixbox 2.0.0
(CC-BY-NC-4.0) and its sole additional dependency are removed from both Cargo
locks and the paint manifest. No optional or legacy mixer remains.

The independent implementation, the K/S derivation and the generated
tables are project MIT; the measured paint data they derive from is CC0
(Revigo, below). The paper supplies the mathematical method, not code,
coefficients or tables. No restricted implementation or data was inspected,
copied or fitted against. Old/new outputs are comparison evidence only, not
generator inputs. The existing spectral.js D65/CIE conversion data remains
under its explicit MIT notice.

This is an engineering inventory, not legal advice or patent clearance.
The public patent-record search found no matching method patent by either
author or Secret Weapons. That result is not a noninfringement opinion.
The paper is linked, not redistributed.

## Scope and reproducibility

The JSON inventory records all **394 observed package rows**: 85 root Rust,
165 watercolor Rust, 100 npm lock entries, 39 sampled Python distributions,
three externally installed npm packages and two pinned generator packages.
Cargo metadata includes lock-resolved optional/platform packages, not only
what one target links. Duplicate packages across workspaces are separate rows.
Local root packages now explicitly declare MIT in their manifests.

There is no pyproject.toml or uv.lock for the audited Python surfaces. The
39-package Python resolution is a CPython 3.12 Linux sample from inline
declarations and test requirements, not a new lockfile or deployed closure.
External pi versions, browser/system libraries, the Nix closure, other wheels
and deployment binaries remain outside a complete binary-distribution audit.
The generator’s two pinned distributions were separately inspected in their
installed wheel metadata and license text.

StyLua’s vendored WASM, JS and license were hash-matched to npm 2.5.2.
Pinned upstream licenses were read for spectral.js, Watercolor Lab, StyLua,
pi-black and kache. Sampled Pillow/certifi/cryptography wheel notices were
inspected. No sakaki access, deployment or painter prompt change occurred.

`pigment-mixer-dependencies.json` gives every observed component, version,
declared license, manifest/registry evidence and action. Registry metadata is
declared-license evidence, not proof of every upstream copyright. `AND`
expressions retain all required terms; `OR` expressions permit a choice.
