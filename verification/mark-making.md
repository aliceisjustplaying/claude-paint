# Mark-making verification

All rows are unrun unless an exact evidence link says otherwise. Agent probes do not make a document verified. Each setup uses an isolated disposable session at the pinned source commit. No fault-injection step targets a user painting.

Base canvas: `canvas{size=100,aspect=5,linen=12,ground={{pile={{"lead white",1}},um=40,apply="knife"}}}`. Base pile: `p=pile{{"red earth",1}}`. A wet patch can be made with `work(rect(200,20,500,150),{hand="body",pile=p,coverage=2,clip=true})`. Visual comparisons use looks before and after each operation, fresh equivalent state and explicit equal seeds. “Save image” uses developer-build PNG saving. Construction-only comparisons also record canvas equality and chunk counts.

For each modifier row below, the first scenario tests its start value and the second tests its during-operation contract. Pending-request tests need two independent clients and an observed running chunk; no inference from a fast completed request is sufficient. Process, storage and external-log fault rows need a disposable copy plus captured logs.
